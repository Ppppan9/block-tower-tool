# 积木塔 · After Effects 工程包使用说明

本压缩包由“积木塔 · 核玩工具”的「导出 AE 工程」生成，包含重建 AE 工程所需的全部内容：

- `build_ae_project.jsx`：AE 脚本（文件 → 脚本 → 运行脚本文件…），读取同目录 `timeline.json` 与 `assets/`、`audio/` 重建工程
- `timeline.json`：合成 / 图层 / 关键帧（时间单位秒，位置单位像素，缩放百分比；图层从下到上）
- `assets/`：所有 2D 素材 PNG（木箱、托盘、HUD、进度条、浮字、弹窗、粒子…，均为游戏内实际用到的图）；`assets/tower/` 为积木塔 3D 画面按变化逐帧预渲染的透明 PNG 序列
- `audio/`：混合音轨与逐事件音效 wav

## 步骤
1. 解压到任意文件夹（不要拆分文件）。
2. AE：文件 → 脚本 → 运行脚本文件… → 选 `build_ae_project.jsx`（首次需在 首选项 → 脚本和表达式 允许脚本写入文件及访问网络）。
3. 脚本完成后弹窗给出图层/关键帧统计，并可另存为 .aep。
4. 打开 **主合成_积木塔** 预览。

## 合成结构（从下到上）
背景 → 积木塔（预合成：逐帧 PNG，每个变化帧一层，按时间切换）→ HUD（等级条、齿轮、木箱队列、托盘、道具）→ 飞行积木 / +1 / 连击字 / 提示气泡 / 粒子 → 弹窗 / 结束页 → 手指 → 混合音轨 / 逐事件音效（预合成）。

## 说明
- 积木塔是 3D 渲染的透明 PNG 序列（`aeTowerFps` / `aeTowerScale` 可调体积）；需要真 3D 请用「导出 3D 动画」（glTF）。
- 图层名可在设置里选中文 / English。
